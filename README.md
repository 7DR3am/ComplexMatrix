# Лабораторная работа №1: Матрицы комплексных чисел

## Описание

Реализация класса для работы с матрицами над полем комплексных чисел на языке Java.

## Структура проекта

- `src/Complex.java` — класс комплексного числа (сложение, вычитание, умножение, деление, сопряжение, модуль).
- `src/Matrix.java` — класс матрицы комплексных чисел.
- `src/Main.java` — консольный интерфейс.

## Возможности

Класс `Matrix` поддерживает:

- сложение матриц (`add`);
- умножение матриц (`multiply`);
- деление матриц через умножение на обратную (`divide`);
- транспонирование (`transpose`);
- вычисление определителя методом Гаусса (`determinant`);
- нахождение обратной матрицы методом Гаусса–Жордана (`inverse`).

## Запуск

### Через IntelliJ IDEA

Открыть `src/Main.java` и нажать зелёную стрелку ▶ **Run 'Main.main()'**.

### Через терминал

```bash
cd src
javac Complex.java Matrix.java Main.java
java Main
